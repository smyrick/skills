# Brand and templates

Use the presenter’s chosen format and supplied template. If a frame feels cramped, shorten the copy or use a layout with fewer slots. Use the template’s chapter layout when the audience moves into a different part of the story, and review the edited slide with its neighbors.

For an external or co-branded deck, use approved assets and the audience-appropriate footer. Preserve clear space around supplied marks. Check that screenshots, examples, claims, and partner marks are cleared for that audience. Apply the same check to speaker notes if they travel with the deck.
